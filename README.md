# Woodland Warrior

Virtual Reality (VR) / Mixed Reality (MR) with the Meta XR SDK Building Block app for Android built with Unity and AR Foundation. It demonstrates the use of Meta XR Building Blocks such as Hand Tracking (MR) and Grab and Locomotion.

## Installation

1. Go to the Releases page of this repository.
2. Download the APK and install it on an  Meta Quest headsets compatible.

## Usage

- **Activity 1 – Grab and Locomotion:** Allows the user to interact with virtual objects using the controllers
- **Activity 2 –  Passthrough and Hand Tracking (MR):** The user can see their real-world environment through the headset and interact with a virtual object using only their hands, rather than controllers.
- **Activity 3 – Additional Building Block:** An additional function.

## History

A Virtual Reality (VR) / Mixed Reality (MR) APK using the Unity Engine and the Meta XR SDK Building Blocks in the Meta Quest headsets. Thanks to the implementation of standard Building Blocks features—such as Grab and Locomotion and Hand Tracking (MR)—the user is able to use their hands to grasp virtual objects (the Minecraft sword) and interact with others (wooden blocks).
